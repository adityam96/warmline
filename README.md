# Warmline

A clickable design mock of a networking inbox for MBA students, built on top of LinkedIn-style messaging.

**Live demo:** https://adityam96.github.io/warmline/

- **Home**: today's plan and highlights worth knowing
- **Inbox**: conversations with suggested replies, tone tweaks and follow-up reminders
- **Calendar**: week and month views of chats, follow-ups, scheduled messages and deadlines

Everything is a single static `index.html`. All people, companies, schools and data are fictional, and nothing is sent anywhere.
